
# OSI Model

## Overview

The **OSI (Open Systems Interconnection) Model** is a conceptual framework used to understand how data travels from one device to another over a network. It divides network communication into seven layers, making it easier to understand, troubleshoot, and design networks.

## Why It Matters# OSI Model

## Overview

The OSI Model is a way to understand how information moves from one device to another on a network. It breaks down network communication into seven layers. This makes it easier for people to understand networks fix problems and design networks. The OSI Model is an important tool for people who work with networks.

## Why It Matters

- It makes it easier to fix problems by breaking down network communication into layers.

- It provides a way for devices from different companies to communicate with each other.

- It is the basis for networking ideas.

- It helps network engineers understand how different protocols work together. The OSI Model is very useful, for network engineers.

## The Seven Layers

| Layer | Name | Examples |

|:-----:|------|----------|

| 7 | Application | HTTP, HTTPS, DNS, FTP |

| 6 | Presentation | SSL, TLS, Encryption, Compression |

| 5 Session | Session establishment and management |

| 4 | Transport | TCP, UDP |

| 3 | Network IP, Routers |

| 2 | Data Link | MAC Address, Switches |

| 1 | Physical | Cables, Fiber Optics, Electrical Signals |

## Mnemonic

The OSI Model can be remembered using the sentence **All People Seem To Need Data Processing**.

- **A** = Application

- **P** = Presentation

- **S** = Session

- **T** = Transport

- **N** = Network

- **D** = Data Link

- **P** = Physical

This sentence helps people remember the seven layers of the OSI Model.

## Real-World Example

When you open **www.google.com**:

1. Your browser sends an HTTP request.

2. The request is encrypted using TLS or SSL if you are using HTTPS.

3. A communication session is started.

4. TCP makes sure the data is delivered correctly.

5. IP figures out where the data needs to go.

6. A switch forwards the data using MAC addresses.

7. The data is sent through cables or wireless signals. This is how the OSI Model works in life.

## Key Takeaways

- The OSI Model has **seven layers**.

- Each layer of the OSI Model has a job.

- Routers mostly work at **Layer 3 (Network)** of the OSI Model.

- Switches mostly work at **Layer 2 (Data Link)** of the OSI Model.

- Hubs work at **Layer 1 (Physical)** of the OSI Model.

- Understanding the OSI Model makes it easier to fix network problems. The OSI Model is an useful tool.
